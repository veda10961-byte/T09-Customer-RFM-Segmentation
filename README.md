# T09 – Customer RFM Segmentation Tool

## Project Overview

This project develops a Customer RFM Segmentation Tool using Recency, Frequency and Monetary (RFM) analysis.

The tool calculates customer-level RFM measures, assigns customers to business segments and recommends a targeted campaign for each segment.

The analysis is based on the Sales dataset provided for the T09 project.

## RFM Methodology

RFM stands for:

- **Recency** – number of days since the customer's most recent purchase
- **Frequency** – number of orders placed by the customer
- **Monetary** – total revenue generated by the customer

Customers receive R, F and M scores from 1 to 5 using quintile-based scoring.

The three scores are combined to support rule-based customer segmentation.

## Customer Segments

The project uses the following segments:

- Champions
- Loyal Customers
- Potential Loyalists
- New / Promising
- At Risk
- Hibernating
- Lost
- Needs Attention

## Campaign Strategy

A targeted campaign is associated with each customer segment.

Examples include:

- **Champions** → VIP Loyalty Campaign
- **Loyal Customers** → Loyalty Upgrade
- **Potential Loyalists** → Second-Purchase Campaign
- **At Risk** → Win-Back Campaign
- **Hibernating** → Come-Back Campaign
- **Lost** → Last-Chance Win-Back

The complete campaign plan is available in the Excel workbook.

## Application Features

The Streamlit application allows users to:

1. Enter a customer ID.
2. Retrieve the customer's RFM profile.
3. View Recency, Frequency and Monetary values.
4. View individual R, F and M scores.
5. View the combined RFM score.
6. View the customer's segment.
7. View the recommended campaign.
8. Receive an error message for an invalid customer ID.

## Verification

The RFM results were verified by comparing selected customer-level calculations with the underlying Sales transactions.

The application was also tested using an invalid customer ID to check error handling.
